# SuperMenu 设计规范

SuperMenu 的目标不是给 Windows 加一条任务栏，而是复刻 macOS 顶栏的**位置、节奏和材质**：
文字在壁纸上呼吸、玻璃折射内容、菜单从栏边弹出，而不是一个带模糊背景的工具栏。

参考：Apple Human Interface Guidelines（Typography、Layout、Motion、Materials）、macOS
Sonoma/Sequoia 的菜单栏、Atrium Desktop 的液态玻璃实现。

## 2. 排版

- 字体：HarmonyOS Sans SC（随软件私有加载，不安装）。四个字重：Light 300、
  Regular 400、Medium 500、Bold 700；正文/菜单取 Regular，强调标题取 Medium，
  页面标题与应用名取 Bold。
- 图标字体：Segoe Fluent Icons，从本机 Windows 11 提取为 `assets/fonts/SegoeIcons.ttf`，
  原生栏通过 DirectWrite 私有集合加载，设置中心通过 `Assets/Fonts/` 加载；不安装到系统。
- 控制中心弹出：Atrium `kPop` 弹簧（response 0.36 s、damping 0.62）从 0.92 缩放到 1，
  带轻微过冲，0.6 s 落定；透明度 160 ms 三次缓出。其他弹窗仍用 190 ms 的轻量缩放。
- 图标动画：充电电池在 BatteryCharging 帧循环；Wi‑Fi/以太网切换播放 WifiAni/EthernetAni；
  音量变化时扬声器脉冲；点击 Wi‑Fi 时 `Wifi1→Wifi2→Wifi3→Wifi` 四帧共 0.3 秒；
  打开控制中心不再播放 Wi‑Fi 动画；播放/暂停切换 Play/Pause 状态字形。
- 控制中心连接胶囊的点击分区：圆形图标区域切换 Wi‑Fi/蓝牙/专注；文字与胶囊其他区域
  打开对应设置页。高频点击先按乐观状态即时重绘，命令文件只保留最新目标，辅助进程
  串行执行无线电切换。
- 专注模式使用实心月亮字形 `MobQuietHoursSolid`（F1DB）；关闭仍保留月亮形状。
- 滑杆图标随数值切换：亮度使用 LowerBrightness/Brightness，音量使用 Volume0–Volume3；
  顶部状态电池字形比同排图标大 28%。
- 回退：Segoe UI Variable Text / 系统中文字体。
- 数字等宽：时钟、音量、电池等开启 tabular figures，避免数字变化时抖动。
- 语言：简体中文与 English；最右侧日期时间顺序为“月日 + 星期 + 时间”
  （中文“11月19日 周四 18:53”，英文“Nov 19, Thu 6:53 PM”）；24 小时制可切换，
  可选显示秒。
- 玻璃上的文字带 32–35% 反色光晕（向下一像素），保证任何壁纸上可读。
- 每个区域独立决定墨色；墨色在 450 ms 内缓动，而不是瞬间翻转。

## 3. 玻璃材质

默认 Liquid 预设（设置中心可调）：

| 参数 | 默认 | 含义 |
|---|---|---|
| transparency | 0.94 | 1 = 完全透出背景，0 = 纯色 |
| blur | 0.52 | mip 模糊量（映射到 BlurLod） |
| refraction | 18 | 边缘折射强度（px，按栏高夹紧） |
| edge | 18 | 折射带宽（px，按栏高夹紧） |
| dispersion | 0.30 | RGB 色散，像真实棱镜 |
| highlight | 0.80 | 镜面高光/内发光 |
| shadow | 0.35 | 底部投影 |
| tint | #FFFFFF | 玻璃色调 |
| saturation | 1.15 | vibrancy |
| noise | 0.015 | 细微颗粒，防止渐变色带 |

Frosted 预设：高模糊、低折射、更高染色；Clear 预设：几乎透明、低模糊、高折射。
预设只是参数的起点，用户继续调单个滑块仍然生效。

玻璃材质统一用于顶栏和所有面板；面板因为要承载菜单文字，额外增加 4% 的 tint。

### 墨色（ink）

- 从 ROI 小 mip 读取显示区域的平均 sRGB 亮度，混入 tint 后判断。
- 亮度 > 0.50 → 深色字（近黑）；< 0.42 → 白色字；中间保持上一状态，防止抖动。
- 文字颜色：白 96% / #111317 92%；次要文字：白 76% / #111317 66%。
- 悬停底板：白 20% / 黑 10%；选中菜单行：系统蓝 #0A84FF 填充、白字。
- 三个独立区域：左侧（菜单）、右侧状态、时钟。

## 4. 动效

| 场景 | 数值 | 曲线 |
|---|---|---|
| 菜单/面板打开 | 190 ms，scale 0.965→1，opacity 0→1 | 缓出三次 + DComp 缩放 |
| 关闭 | 130 ms，scale 1→0.955，opacity 1→0 | 缓出 |
| 悬停底板 | 约 60–120 ms | 指数趋近（20 / 10 per s） |
| 墨色切换 | 450 ms | 缓出三次 |
| 自动隐藏 | 550 ms 停留后立即隐藏 | 为兼容 DWM 合成，不做逐帧滑出 |
| 控制中心/日期时间 | Atrium `kPop` 0.6 s | response 0.36 s、damping 0.62；0.92→1 轻微过冲，160 ms 淡入 |

所有动画按真实时间推进，与刷新率无关；用户可在设置中关闭菜单动画。

## 5. 菜单与面板的“macOS 感”

- 顶级菜单打开时，对应顶栏项保持高亮；鼠标滑到另一个顶级菜单时内容直接切换，
  不重新弹一下。
- 菜单行高 23 DIP、左侧 18 DIP 的勾选列、右侧快捷键；分隔线 1 px。
- 面板从菜单栏下方 3–4 DIP 处出现，圆角完整，四边都有柔和投影；面板不抢焦点。
- 点击面板外部只关闭面板，不吞掉那一次点击；Esc 关闭；菜单支持 ↑/↓/Enter。
- 控制中心卡片是半透明白色（深色背景上 13%，浅色背景上 62%），不是实心卡片；
  蓝色用于功能图标和滑块填充。
- 日期时间弹层顶部数字时钟包含秒，每秒刷新；今天为蓝色实心圆（无自定义日期选择），
  点击整块迷你日历区域打开系统日历。星期从周日开始（中文显示“日 一 二 …六”）。
- 允许在设置中把栏移到其他显示器、调整高度、字号、模块与工作区行为。

## 6. 与 Atrium 的差异

| 方面 | Atrium | SuperMenu |
|---|---|---|
| 位置 | 底部胶囊 Dock | 顶部全宽菜单栏 |
| 形状 | 胶囊，大圆角 | 栏为直角贴边，面板为 G3 圆角 |
| 内容 | 应用图标、开始菜单、托盘、小组件 | macOS 菜单、状态区、控制中心、日历 |
| 材质 | 液态/磨砂，实时 DDA | 同一套液态玻璃 shader 与参数映射 |
| 捕获 | DDA + WGC + 壁纸 | DDA + 壁纸（去掉 WinRT/WGC 依赖） |
| 窗口 | 双 DComp 层（玻璃/内容分线程） | 单 swap chain、单视觉层，降低同步复杂度 |

SuperMenu 引用 Atrium 的 shader 结构和设计规范，但代码、布局与交互为本项目独立实现。

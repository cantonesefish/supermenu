# Filled Control Center icons

Solid glyphs from **Remix Icon** (`fill` variants):

- Source: https://github.com/Remix-Design/RemixIcon
- License: Apache License 2.0.
- Icons: Device/wifi-fill, Device/bluetooth-fill, Device/computer-fill,
  Weather/moon-fill, Weather/sun-fill, Media/volume-up-fill,
  Media/play-fill, Media/pause-fill, Media/skip-back-fill,
  Media/skip-forward-fill.
- Files are kept as the editable source; normalized path data is compiled into
  `native/src/sf_icons_data.h` under the `fill_*` keys.

# SF-style status icons

Selected symbols from **Open Symbols** by OrchardKit, Lucide 1.49.0:

- Source: https://opensymbols.dev/lucide and https://github.com/OrchardKit/open-symbols
- Original icon set: Lucide (https://lucide.dev), ISC License.
- Downloaded 2026-11-19 from the `previews` assets.
- Files: wifi / wifi-off / ethernet-port / battery* / search /
  sliders-horizontal / bluetooth / monitor / moon / sun / volume* /
  bell / play / pause / skip-back / skip-forward / chevron-*.
- The SVG path data is compiled into `native/src/sf_icons_data.h`; these
  files are kept as the editable source/asset snapshot.
- Open Symbols converts open-source icons into SF Symbols-style silhouettes;
  they are not Apple's proprietary SF Symbols and do not ship Apple fonts.

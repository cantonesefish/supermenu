# Logo artwork

- `windows-logo-2021.svg` — Windows 11 logo, downloaded 2026-11-19 from Wikimedia Commons:  
  https://commons.wikimedia.org/wiki/File:Windows_logo_-_2021.svg  
  The file consists only of simple geometric shapes (four blue panes, `#0078D4`).
  "Windows" is a trademark of Microsoft Corporation; the mark is used only to
  identify the configurable Windows logo option, not to imply affiliation.

The Apple silhouette used by the menu bar is not stored here; its vector path is
derived from the Font Awesome Free `apple` brand icon (CC BY 4.0), embedded in
`native/src/icons.cpp` and credited in `THIRD_PARTY_NOTICES.md`.
